# Video de demostración

Sube aquí el video (por ejemplo `calabozo_gestos.mp4`).

Orden sugerido para grabarlo en una sola toma (espera a volver a la sala principal entre cada gesto, ~5 s):

1. Sala principal (sin gesto)
2. Praise the Sun — dos manos sobre la cabeza
3. Apuntar al frente — índice hacia la cámara
4. Signo de paz ✌️
5. Puño cerrado ✊
6. Mano abierta apuntando a la derecha
7. Mano abierta apuntando a la izquierda

Si el archivo pesa más de 25 MB no se puede subir desde la web de GitHub (límite de subida por navegador); en ese caso comprímelo o súbelo con GitHub Desktop (límite 100 MB por archivo).
